# 美妆个护红包助手 · 平台规则与叠加指南

## 一、各平台红包规则

### 天猫美妆
- **领取条件**：天猫用户均可领，美妆超级品牌日、88VIP 美妆券为主。
- **使用门槛**：美妆品类满减券（示例满 1000 减 100，以平台实时为准）。
- **有效期**：大促期券面短（3–5 天），品牌日券当日有效。
- **是否可叠加**：可与跨店满减、88VIP 95 折、品牌会员券叠加。

### 京东美妆
- **领取条件**：京东用户均可领，PLUS 会员有美妆专属券。
- **使用门槛**：京东美妆满减券，护肤/彩妆/个护分品类。
- **有效期**：领取后数日内有效。
- **是否可叠加**：可与跨店满减、京豆、E 卡叠加。

### 拼多多/抖音美妆
- **领取条件**：拼多多百亿补贴美妆专场直降；抖音直播间限时券。
- **使用门槛**：百亿补贴价无门槛；抖音直播间券限单场。
- **有效期**：百亿补贴价每日微调；直播间券当场有效。
- **是否可叠加**：百亿补贴部分叠店铺券；抖音直播间券与店铺券部分可叠。

## 二、红包叠加逻辑

叠加顺序：平台美妆品类券 → 跨店满减 → 88VIP 95 折/PLUS 折扣 → 品牌会员券 → 支付优惠。

技巧：
1. **大牌护肤（精华/面霜）**：先领品类券，再叠跨店满减，88VIP 95 折再减一层。
2. **小样套装试水**：不确定肤质适不适合，先买小样/中样套装，比正装便宜且能试用；小样折算正装价更划算。
3. **品牌日蹲券**：雅诗兰黛周二会员日、兰蔻会员日等品牌日历，当天券面最大（示例，以品牌官方为准）。

## 三、美妆个护专属知识要点

### 3.1 正装 / 小样 / 中样规格差异
- **正装**：标准容量（如精华 30ml、面霜 50ml），带完整外包装与说明书，单价高但每 ml 最便宜。
- **小样**：通常 5ml–15ml，无外盒、包装简易，正装的 1/3–1/6 容量；大促常作为赠品或套装单独卖。
- **中样**：15ml–30ml，介于两者之间，差旅装常见。
- **折算公式**：小样单价 ÷ 容量（ml）× 正装容量 = 折算正装价；若折算价高于正装价×0.7，说明小样套装并不便宜。
- **注意**：部分"小样"实为分装罐假货，认准品牌官方小样/专柜赠品/官方旗舰店赠品区。

### 3.2 开封后有效期（PAO）
- 护肤品瓶身有"开盖小罐子"图标（如 12M = 开封后 12 个月内用完）。
- 未开封护肤品保质期通常 3 年，彩妆 3–5 年（示例，以产品标注为准）。
- 已开封超过 PAO 期限，即使没变质也建议停用；临期护肤品折扣大但要算自己多久能用完。

### 3.3 敏感肌测试
- 新品（尤其是酸类、维 A 类、美白类）上脸前先在耳后或前臂内侧涂一点，等 24–48 小时无红肿刺痛再上脸。
- 红包活动页推的"急救/速效"产品，敏感肌不要跟风；护肤品不宣称疗效，"药妆"字样在国内不允许作为宣传。
- 成分踩雷区：酒精、香精、酸类浓度高、新版配方未在你肤质上验证过的，谨慎囤货。

### 3.4 大促囤货节奏
- **3.8 女王节、618、双 11**：全年美妆券力度最大，正装+赠品小样最多。
- **品牌日**：雅诗兰黛周二、兰蔻会员日、SK-II 品牌日等，当天会员双倍积分+限量套装（示例，以品牌官方为准）。
- **换季前**：换季护肤需求（春夏防晒、秋冬保湿）在换季前 2 周大促囤货。

## 四、新客与老客区别
- **新客**：天猫美妆新人券、京东美妆首单券、品牌新客礼（小样套装）。
- **老客**：品牌会员日券、88VIP/PLUS 专属券、回购券。
- **新老客都可领**：跨店满减、百亿补贴。
- 新客券面额大但只一次，留给精华/面霜等大件护肤，别用在纸巾沐浴露等日耗上。

## 五、避坑指南
1. **"药妆/医美级"宣传违规**：国内化妆品不允许宣称疗效，"药妆"是违规词；遇到此类宣传的产品要警惕。
2. **临期/过期假货**：超低价大牌小样可能是分装假货或临期品，认准官方渠道。
3. **小样折算反而贵**：看着套装一堆，算每 ml 单价可能比正装还贵，下单前算折算价。
4. **囤货过期**：护肤品开封后 6–12 个月用完，别一次囤三年量；未开封 3 年内用完。
5. **自动续费会员**：美妆 App/品牌会员自动续费首月优惠，忘了关会按月扣，设个提醒。
6. **"付费内测/内部员工价"骗局**：大牌没有所谓内部员工代购渠道，都是骗子。
